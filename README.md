# Student-Depression-Dashboard

### 🗄️ SQL Server | 📊 Tableau | 🔍 Data Analytics

A data analytics project focused on exploring different **academic, financial, lifestyle, and satisfaction-related factors** affecting students.

The project combines **Microsoft SQL Server for data preparation and analysis** with **Tableau for interactive visualization and dashboard creation**.

---

## 🎯 Objective

The main objective of this project was to transform a raw student dataset into a structured analytical dataset and use visualization to identify patterns across different student-related factors.

---

## 🔧 What I Did

### 1️⃣ Data Preparation with SQL Server

The raw dataset was first imported into **Microsoft SQL Server**.

SQL was then used to:

* Clean and modify the existing data
* Update categorical values
* Modify the **Gender** column
* Create an **Age Group** column
* Add and update required fields
* Examine column distributions
* Prepare the dataset for further analysis

---

### 2️⃣ Data Analysis

After cleaning and transforming the data, SQL queries were used to analyze student-related attributes and understand their distribution across the dataset.

The analysis focused on factors such as:

**Academic Pressure • Financial Stress • Sleep Duration • Study Hours • Student Satisfaction**

---

### 3️⃣ Tableau Visualization

The processed SQL Server data was imported into **Tableau** and converted into an interactive dashboard.

The dashboard presents:

| Analysis                | Visualization |
| ----------------------- | ------------- |
| 📚 Academic Pressure    | Student Count |
| 💰 Financial Stress     | Student Count |
| 😴 Sleep Duration       | Student Count |
| 📖 Study Hours          | Student Count |
| 😊 Student Satisfaction | Student Count |

---

## 📊 Dashboard Highlights

### 📚 Academic Pressure

Visualizes the number of students across different academic pressure levels.

### 💰 Financial Stress

Shows the distribution of students across different financial stress levels.

### 😴 Sleep Duration

Compares student counts across different sleep-duration categories.

### 😊 Student Satisfaction
